# 实时目标检测

基于 ncnn 的端侧推理引擎，YOLOv8n INT8 量化模型，四级流水线异步处理，支持 Linux V4L2 摄像头。

## 编译

```bash
mkdir build && cd build
cmake ..
make -j4
```

## 运行

把 YOLOv8n INT8 量化模型放到 `model/` 目录下：

```bash
./EdgeVisionGateway
```

默认使用 `/dev/video0`，640x480。参数在 `main.cpp` 里改。

## 优化

做了一些优化，以下是测试数据：

- **内存池**：每次分配 126.1 us，换成预分配帧缓冲复用降到 4.9 us，快了约 96%
- **预处理**：全图 resize 加归一化 1.25 ms，改成只处理有效区域降到 0.73 ms，快了约 42%
- **颜色转换**：NV21 转 RGB 浮点运算 1.34 ms，换成整数定点运算 0.82 ms，快了约 39%
- **流水线**：单线程串行 5.1 FPS，改成四个阶段异步并行提到 6.6 FPS，提升了约 29%
- **无锁队列**：多线程下 SPSC 比 Mutex 队列吞吐高约 10 倍

## 依赖

- C++17（GCC 7+）
- ncnn
- OpenMP（可选）

## 优化方向

- 目前只支持 V4L2 摄像头，后续可以加图片文件、视频流、RTSP 等多种输入方式
- 推理是当前最大瓶颈，可以试试换更小的模型或者进一步量化
